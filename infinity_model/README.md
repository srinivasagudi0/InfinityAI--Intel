# Infinity-0

The first native Infinity language model from scratch.

## What this is

Infinity-0 is small transformer language model trained entirely from scratch.
No Qwen. NO Llama. No OpenAII. No wrappers. Every weight is ours.

## Goal

Train a model small enough to run on a laptop, but real enough to prove the architecture works.
Later versions (Infinity-1, Infinity-2, etc) will be larger and more powerful and will be trained on bigger datasets.
